## Токены и фактические значения

- Фон: `--bg: #0B0D10`.
- Основной текст: `--fg: #F4F3F0` — контраст с фоном ≈ **17.53:1**, проходит WCAG AA/AAA.
- Вторичный текст: `--muted: #97A0A8` — ≈ **7.33:1**, проходит.
- Красный акцент: `--accent: #EF4B45` — ≈ **5.34:1**, проходит для обычного текста.
- Серый в крупном hero-тексте: `#66717A` — ≈ **3.90:1**; допустим только для крупного текста, для мелких подписей не использовать.
- Основные гарнитуры подключаются через Google Fonts с `display=swap`, но стек будет дополнен системными fallback.

## Расхождения с ТЗ до правок

### Типографика

- `.eyebrow`: `0.67rem` ≈ 10.7px — ниже T-2.
- `.section-index`: `0.65rem` ≈ 10.4px — ниже T-3.
- `.meta-cell`: `0.66rem` ≈ 10.6px — ниже T-2.
- `.footer`: `0.68rem` ≈ 10.9px — ниже T-2.
- `.mail`: `0.68rem`, на мобильном `0.58rem` — слишком мелко; область нажатия не гарантирует 44×44px.
- Цветовые значения для вторичного текста частично заданы напрямую, а не через токены.

### Бегущая строка

- Весь ticker помечен `aria-hidden="true"`, поэтому полезные названия брендов не доступны скринридеру.
- Дубликат для бесшовной анимации не отделён семантически от оригинала.
- Нет паузы на `:hover`/`:focus-within`.
- В `prefers-reduced-motion` анимация отключается глобально, но дублированный набор остаётся визуально в разметке.
- Нет явной структуры списка.

### Иконки направлений и дублирование

- В карточках используются крупные декоративные буквы `E` и `A`; I-1 не выполнен.
- Блок `signal-stage` и карточки `directions` одновременно работают как ссылки на те же два направления; роли дублируются.
- Карточки повторяют CTA «Открыть направление».

### Доступность и семантика

- Нет общего `:focus-visible` для ссылок и кнопок.
- Нет skip-link.
- Навигация находится непосредственно внутри `main`, отдельного `header` нет.
- Touch targets навигации меньше 44px по высоте.
- Мобильная шапка может быть тесной при 360–390px из-за lockup + трёх ссылок.

### Техническая часть

- `canonical` и `og:url` для главной совпадают: `https://gutsu.space/`.
- `CNAME` содержит `gutsu.space`.
- Основные ресурсы подключаются относительными путями или по HTTPS; mixed-content в коде не найден.
- `og:image` отсутствует; Twitter card = `summary`, а не `summary_large_image`.
- Workflow Pages публикует только ветку `main`; работа в `design-fixes` не затрагивает production до merge.
- Enforce HTTPS — настройка GitHub Pages, не кодовая правка.

## Решения для этапов 1–4

- Сохраняем фирменную систему и тексты.
- Первые Equipment/AI секции остаются входом в направление с CTA.
- Нижние карточки становятся информационными блоками «что входит / для кого / как считаем» без повторного CTA.
- Equipment icon: линейная камера. AI icon: линейная схема узлов.
- Вводим `--accent-equipment: #EF4B45` и `--accent-ai: #8BAFFF`; оба проходят требуемый контраст на `#0B0D10`.
- Кейсы не публикуем: подтверждённых клиентских кейсов/метрик в материалах нет.
- Для social preview готовим 1200×630 макет на базе утверждённого логотипа без изменения его геометрии.
